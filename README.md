# MathSolver V10 Expert Modes

Для каждого из 10 предметов теперь используется отдельный экспертный системный промпт.

Предметы:
- Математика
- Русский язык
- Физика
- Химия
- Биология
- Информатика
- География
- История
- Обществознание
- Английский

Команда `/expert` показывает текущий экспертный режим.

Все функции V9 сохранены:
- Telegram Stars и Premium;
- бесплатная проверка решения по фото;
- ОГЭ/ЕГЭ;
- мини-уроки и тренировки;
- админка;
- история и избранное.

После Deploy:
1. `/status` → `Версия: V10 Expert Modes`
2. Выбрать `📚 Предметы`
3. Выбрать предмет
4. `/expert`
