# MathSolver Stable V5 Pro

Новое:
- кнопка `▶️ Старт` в основной клавиатуре;
- постоянное состояние пользователя через SQLite;
- история диалога сохраняется локально;
- выбор класса и режима сохраняется;
- кнопки под ответом:
  - `🟢 Проще`
  - `🎯 Только ответ`
  - `📘 Подробнее`
  - `⭐ В избранное`
- раздел `⭐ Избранное`;
- `/status` показывает версию и состояние;
- сохранена строгая очистка Markdown/LaTeX из V4.

Важно:
на бесплатном Render локальный SQLite-файл может исчезнуть при полном пересоздании
инстанса. Для действительно постоянной истории между любыми redeploy в будущем
лучше подключить внешнюю PostgreSQL БД. Для обычной работы между запросами и
перезапусками процесса эта версия уже удобнее.

Переменные Render:
BOT_TOKEN
WEBHOOK_SECRET
BASE_URL
GROQ_API_KEY
GROQ_TEXT_MODEL
GROQ_VISION_MODEL
DB_PATH=data/mathsolver.db
