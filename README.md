# MathSolver V10.1 Literature

Добавлена 📖 Литература как 11-й предмет.

Что есть по литературе:
- 9 / 10 / 11 класс;
- отдельный экспертный режим;
- вопросы по произведениям и авторам;
- анализ персонажей;
- тема, идея, конфликт, композиция;
- художественные средства;
- анализ стихотворений;
- мини-уроки;
- тренировки;
- задания по фото;
- ОГЭ/ЕГЭ;
- помощь с сочинением.

Важно:
экспертный режим не должен выдумывать точные цитаты. Если формулировка цитаты
неизвестна наверняка, бот пересказывает смысл без кавычек.

Все функции V10 сохранены:
- Telegram Stars;
- Premium;
- бесплатная проверка решения по фото;
- веб-админка;
- история и избранное;
- экспертные режимы остальных предметов.

После Deploy:
1. `/status` → `Версия: V10.1 Literature`
2. `📚 Предметы`
3. `📖 Литература`
4. `/expert`
