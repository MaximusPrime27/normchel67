# MathSolver V10.2 Fast Photo

Главное изменение: фото теперь анализируется значительно быстрее.

## Новый поток фото

Раньше:
OpenCV -> 9 OCR-проходов Tesseract -> Groq Vision -> ответ

Теперь:
сжатие изображения -> Groq Vision -> ответ

Tesseract запускается только как fallback, если Vision не сработал.

## Что сохранено

- 11 предметов;
- экспертные режимы;
- литература;
- Telegram Stars;
- Premium;
- бесплатная проверка решения по фото;
- админка;
- ОГЭ/ЕГЭ;
- история и избранное.
