# MathSolver V10.3 Photo UX

Фото теперь удобнее использовать.

## Новый сценарий

После отправки фото бот показывает две кнопки:

- 📸 Решить всё фото
- ✂️ Выбрать область

Если на фото одно задание — нажимай `📸 Решить всё фото`.

Если на листе несколько заданий или лишний текст — нажми `✂️ Выбрать область`,
после чего появятся:

- Верх
- Центр
- Низ
- Левая часть
- Правая часть
- Всё фото

## Скорость

Сохранён быстрый режим V10.2:
Vision анализирует фото первым, OCR запускается только как fallback.
