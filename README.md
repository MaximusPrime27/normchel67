# MathSolver V6 Ultimate

Полноценный учебный Telegram-бот для 9–11 классов.

## Добавлено в V6

### Учёба
- мини-уроки по темам;
- тренировки;
- проверка ответа ученика;
- объяснение ошибки;
- похожие задания;
- другой способ решения;
- «что повторить»;
- выбор 9/10/11 класса.

### Математика
- Groq AI;
- SymPy как проверенный точный слой;
- системы, уравнения, производные, интегралы, выражения;
- ОГЭ/ЕГЭ;
- точный результат передаётся ИИ как приоритетный.

### Русский язык
- программа 9–11;
- ОГЭ/ЕГЭ;
- правила, разбор и объяснение;
- тренировочные темы по классу.

### Фото
- OpenCV;
- Tesseract OCR;
- несколько OCR-режимов;
- прямой анализ изображения vision-моделью;
- отдельный режим «Проверить решение»:
  бот ищет первый неверный шаг ученика.

### Пользователь
- профиль;
- статистика;
- история;
- избранное;
- класс и режим сохраняются в БД.

### Стабильность
- rate limit;
- таймауты;
- retries;
- Groq primary;
- optional OpenAI-compatible fallback provider;
- cache одинаковых запросов;
- `/health`, `/ready`, `/status`, `/version`;
- финальная очистка Markdown/LaTeX перед Telegram.

### Админ
Укажи `ADMIN_IDS`, например:

```text
ADMIN_IDS=123456789
```

После этого доступна:

```text
/admin
```

## База данных

По умолчанию:

```text
DATABASE_URL=sqlite:///data/mathsolver.db
```

Это запускается без дополнительной настройки.

Для действительно постоянной истории при полном пересоздании Render
можно позже заменить `DATABASE_URL` на PostgreSQL URL. Код менять не нужно.

## Резервный ИИ

Опционально можно подключить любой OpenAI-compatible API:

```text
FALLBACK_API_BASE=https://provider.example/v1
FALLBACK_API_KEY=...
FALLBACK_MODEL=...
```

Если Groq временно недоступен, бот попробует резервный API.

## После обновления

1. Загрузить содержимое архива в GitHub.
2. Дождаться Deploy.
3. Открыть `/health`.
4. В Telegram:
   `/status`
5. Должно быть:
   `Версия: V6 Ultimate`

Существующие обязательные переменные Render менять не нужно:
- BOT_TOKEN
- WEBHOOK_SECRET
- BASE_URL
- GROQ_API_KEY
- GROQ_TEXT_MODEL
- GROQ_VISION_MODEL

Новые переменные можно пока не заполнять — бот запустится без них.
