# MathSolver Stable V4 Plain

Главное изменение V4:
- ВСЕ ответы проходят через `send_plain()` непосредственно перед отправкой в Telegram.
- Это касается текста, фото, OCR, Groq и локального решателя.
- Markdown и LaTeX физически очищаются перед `message.answer()`.
- `/status` показывает `Версия: Stable V4 Plain`, чтобы можно было проверить, что Render действительно обновился.

Проверка после Deploy:
1. Отправить `/status` — должна быть строка `Версия: Stable V4 Plain`.
2. Отправить `2x² - 5x - 3 = 0`.
3. В ответе не должно быть `###`, `\frac`, `\sqrt`, `\cdot`, `\[`, `\]`.

Переменные Render менять не нужно.
